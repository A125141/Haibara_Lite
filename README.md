# 🛠️ VBS Virus Generator (Educational Tool)

**Author:** A125141  
**Version:** v1  
**Category:** ⚠️ Educational / Malware Simulation  
**Language:** Python  
**Note:** This tool is for **educational purposes only**.

---

## 📖 Overview

This is a **terminal-based educational tool** built with Python that simulates the creation of fake viruses (in `.vbs` format). These "viruses" are not harmful and are used to demonstrate **social engineering concepts**, **automation**, and **file generation** with a fun interactive UI.

---

## 🎮 Features

- Animated loading and ASCII intro screen 🎨
- Menu-based virus generation system
- Supports 3 simulated virus types:
  - 🪟 `Pop-Up`: harmless spam message box
  - 👻 `Ghost`: fake ransomware-style prank
  - ♻️ `Restro`: annoyance loop
- File generation system with `.vbs` output
- Educational HELP and contact section
- Clean and simple terminal UI using `colorama`

---

## 🧠 Why?

This tool was built for beginners and cybersecurity students who want to:
- Practice scripting and file generation in Python
- Understand how VBS files work
- Simulate threat behavior **ethically** in a safe, offline environment
